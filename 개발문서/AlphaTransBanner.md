# AlphaTransBanner

배너 표시 영역의 UI 오브젝트에 `AlphaTransBanner`를 추가합니다. 드래그 및 스크롤 입력은 처리하지 않으며, 이전 배너와 다음 배너를 같은 영역에 겹쳐 알파로 전환합니다.

## 인스펙터 설정

- `Banner Sprites`: 표시할 스프라이트를 순서대로 할당합니다. 비어 있는 항목은 건너뛰며, 이벤트의 인덱스는 원래 목록 기준입니다.
- `Start Index`: 처음 표시할 배너 인덱스입니다. 0부터 시작합니다.
- `Loop`: 기본 켜짐입니다. 마지막 다음에 첫 배너를 표시합니다. 끄면 양 끝에서 멈춥니다.
- `Display Root`: 표시 영역의 RectTransform입니다. 비워두면 컴포넌트 자신의 RectTransform을 사용합니다.
- `Image A`, `Image B`: 전환에 사용할 두 UI Image입니다. 직접 배치하려면 같은 부모 아래 같은 영역에 겹쳐 할당합니다. 비워두면 표시 영역을 채우는 자식 이미지 두 개를 자동 생성합니다. 직접 할당한 이미지의 위치/크기는 수정하지 않습니다.
- `Preserve Aspect`: 이미지 비율을 유지할지 설정합니다.
- `Fade Duration`: 기본 0.5초입니다. 현재 배너는 알파 100→0%, 다음 배너는 0→100%로 동시에 전환합니다. 0이면 즉시 교체합니다.
- `Fade Curve`: 전환 속도 곡선입니다.
- `Use Unscaled Time`: 기본 켜짐입니다. 게임 시간이 정지해도 배너는 전환합니다.
- `Auto Advance`: 기본 켜짐입니다. 끄면 자동 순환하지 않습니다.
- `Auto Advance Interval`: 기본 5초입니다. 배너를 완전히 표시한 뒤 다음 전환을 시작하기까지의 시간입니다. 전환 시간은 별도입니다.
- `On Banner Focused`: 전환 완료 시 현재 배너의 인덱스/스프라이트를 전달합니다.

목록이 비어 있으면 이미지를 숨깁니다. 유효한 스프라이트가 하나면 그대로 표시하며 불필요한 전환을 하지 않습니다. 두 개면 번갈아 순환합니다. 전환이 끝난 이미지는 재사용하므로 반복할 때마다 이미지 오브젝트를 생성하지 않습니다. 일반적인 부모 Mask/RectMask2D를 사용할 수 있습니다.

## 외부 호출

- `Next()` / `Previous()`: 다음/이전 배너로 알파 전환합니다. 전환 중 연속 호출은 무시합니다.
- `SetPage(int index)`: 해당 배너로 알파 전환합니다.
- `SetPage(int index, bool animate)`: false로 호출하면 전환 중에도 즉시 교체합니다.
- `SetSprites(IEnumerable<Sprite> sprites, int initialIndex = 0)`: 목록을 교체하고 초기 배너를 즉시 표시합니다.
- `SetAutoAdvance(bool enabled)`: 자동 순환을 설정합니다.
- `Refresh()`: 인스펙터 목록 등 변경 후 현재 배너를 다시 표시합니다.
- `CurrentIndex`, `CurrentSprite`, `IsTransitioning`: 현재 상태를 읽습니다. 전환 중에는 아직 확정되지 않은 다음 배너가 아니라 기존 배너를 반환합니다.

배너가 비활성화되는 도중에 전환 중이었다면 다음 배너를 완전히 표시한 상태로 정리합니다. 다시 활성화하면 이 배너부터 이어집니다. 인스펙터 런타임 변경은 OnValidate에서 UI를 직접 수정하지 않고 다음 Update에 반영합니다.

## HSB에서 교체

기존 `HorizontalScrollBanner`와 씬은 자동 변경하지 않습니다. 새 표시 오브젝트로 교체하거나 기존 HSB와 기존 배너 컨테이너를 제거한 뒤 새 컴포넌트를 사용합니다. HSB 컴포넌트만 꺼두면 기존 배너 이미지가 남아 겹쳐 보일 수 있습니다. 새 배너는 레이캐스트를 막지 않으며 드래그 핸들러가 없습니다.

`AlphaTransBannerTests`에 양쪽 알파/포커스 확정, 반복/이미지 재사용, 자동 순환, 빈 목록/단일/두 개/빈 항목, 루프 경계, 즉시 변경, 비활성화 중 전환 정리, 검증 시 갱신 지연, 마스크 및 드래그 미지원 테스트를 추가했습니다. 컴파일 검증과 Unity Test Runner/실제 화면 검증은 구분해서 확인해야 합니다.
