# 타겟별 커서 오프셋과 캐릭터 해금 디버그

## 커서 위치 오프셋

각 아이콘의 `TraverseTarget > Cursor Target > Cursor Offset`에서 X/Y/Z를 지정합니다. 기본은 (0, 0, 0)으로 기존 위치와 같습니다.

오프셋은 `Cursor Anchor`의 로컬 좌표입니다. Anchor가 없으면 타겟 자신의 Transform을 기준으로 하며, 기준 Transform과 Canvas의 회전/배율을 반영합니다. 예를 들어 회전되지 않은 UI에서 X를 늘리면 오른쪽, Y를 늘리면 위쪽으로 이동합니다.

마우스 호버·방향키 순회·즉시 이동·이동 애니메이션·선택 후 위치 추적에 같은 오프셋을 사용합니다. Play Mode에서 인스펙터의 오프셋이나 Anchor 할당을 변경하면 같은 프레임의 LateUpdate에 새 위치로 맞춥니다. 이동 중이었다면 이동 애니메이션을 중지하고 즉시 반영하며, 선택 상태와 현재 타겟은 유지합니다. Time.timeScale이 0인 일시정지 상태에서도 반영됩니다. 기준 Transform이 이동하면 기존처럼 계속 따라갑니다.

외부 스크립트에서는 `TraverseTarget.SetCursorOffset(Vector3)`로 변경할 수 있습니다. 인스펙터 변경과 같은 처리 경로를 사용하며 재호버나 재선택은 필요하지 않습니다. 커서가 숨겨져 있을 때는 강제로 표시하지 않고 다음 활성화 시 최신 오프셋을 사용합니다.

## 캐릭터 전체 활성화

캐릭터 선택 커서의 `TraverseCursor > Debug > Debug Unlock All Characters`를 체크합니다. 기본은 꺼짐입니다. 실행 전에 체크하거나 Play Mode에서 변경할 수 있습니다. 런타임 인스펙터 변경은 다음 Update에 반영됩니다.

체크하면 모든 캐릭터의 해금 제한을 일시적으로 우회하여 호버/순회/선택/출격이 가능합니다. 잠금 때문에 적용된 Dim은 해제되지만, 다른 캐릭터를 선택했을 때의 Dim은 그대로 유지됩니다. 비활성 GameObject나 상호작용 불가능한 Selectable을 강제로 켜지는 않습니다.

실제 도전과제 수, 캐릭터 정의의 기본 해금 여부/해금 조건, 저장 데이터는 변경하지 않습니다. 퀘스트의 다음 캐릭터 해금 안내도 실제 진행도를 기준으로 유지합니다.

체크 해제, 커서 컴포넌트 비활성화, 커서 오브젝트 비활성화/파괴 시 실제 해금 상태로 돌아갑니다. 단순히 커서의 `Deactivate()`로 가시성과 순회만 끈 경우에는 디버그 옵션이 유지됩니다. 출격 요청은 UI가 닫히기 전에 선택 정보를 확정하므로 테스트 캐릭터로 정상 출격할 수 있습니다.

여러 커서가 이 옵션을 체크한 경우 하나라도 활성화된 디버그 커서가 남아 있으면 전체 활성화가 유지됩니다. 배포할 씬/프리팹에서는 체크를 해제해야 합니다. 다른 코드에서 즉시 변경하려면 `TraverseCursor.SetDebugUnlockAllCharacters(bool)`을 호출합니다.
